# GetGoin brand assets

Drop-in logo files for branding, promotion, social, and press.

## Files

| File | Use |
| --- | --- |
| `getgoin-icon.png` (1536²) / `.svg` | App icon / avatar / favicon source. Dark rounded tile, white **G**, blue paper-plane. |
| `getgoin-wordmark.png` (3120×900) / `.svg` | Wordmark for **light** backgrounds. |
| `getgoin-wordmark-light.png` / `.svg` | Wordmark for **dark** backgrounds (white "Get"). |
| `getgoin-lockup.png` (3960×1080) / `.svg` | Icon + wordmark, horizontal. For **light** backgrounds. |
| `getgoin-lockup-light.png` / `.svg` | Icon + wordmark for **dark** backgrounds. |

All PNGs are **transparent (RGBA)** and high-resolution — scale down freely.
SVGs are vector (infinite scale) and editable.

## Colors

| Token | Hex | Use |
| --- | --- | --- |
| Ink | `#171717` | Tile background, "Get", body text |
| Blue | `#2563eb` | "Goin", paper-plane accent, links/CTAs |
| Off-white | `#fafafa` | Page/canvas background |
| Gray | `#525252` | Secondary text |

## Type

**Inter, 800 (ExtraBold)**, letter-spacing ≈ −2%. The PNGs are baked with Inter.
The SVGs reference Inter with a system-sans fallback — install Inter (or convert
text to outlines in your design tool) for an exact match.

## Don'ts

- Don't recolor the wordmark (keep Ink + Blue).
- Don't add effects/shadows to the icon tile.
- Keep clear space around the lockup ≈ the height of the "G".
- On dark backgrounds use the `-light` variants.
